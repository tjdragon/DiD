# Decentralised Identity 

- Ce qui suit est en langue francaise

## Contexte

- Le W3C definit une spec "DID" https://www.w3.org/TR/did-1.0/
- Le but de ce projet est de creer un tutoriel qui permet de comprendre son fonctionnement au travers d'un exemple concret.

## DiD avec la blockchain

- J'utilise DFNS https://www.dfns.co/ - j'ai deja quelques projets qui fonctionnent avec DFNS: /home/tj/Code/DFNS
- Le but est de creer un tutoriel avec du code qui fonctionne en TypeScript et qui utilise DFNS pour la gestion des cles privee et publique.
- Je veux que tu designe une architecture logicielle qui permet de mettre en place ce tutoriel.

## Cas concret

- Une entite officielle connait ma date de naissance - par exemple le gouvernement
- Je veux utiliser le DiD pour prouver mon age sans reveler ma date de naissance
- Par example, pour entrer dans un bar, on me demande de prouver que j'ai plus de 18 ans
